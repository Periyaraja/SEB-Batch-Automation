# SEB Batch Automation

A Windows Batch automation experiment created by NightOwl.

## Overview

This project demonstrates Windows batch scripting for automating installation-related tasks and interacting with a Windows application environment.

The original experiment also involved patch-related testing in a controlled and isolated lab environment.

## Lab Notice

The patch-related functionality from the original experiment is intentionally omitted from this public repository.

This project was developed and tested exclusively in a controlled, isolated environment for learning and experimentation.

No patch executable or target-specific patch implementation is included in this public repository.
